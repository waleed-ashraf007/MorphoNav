# High-Level (Raspberry Pi + ROS 2)

Use this area for:

- `rpi/`: Raspberry Pi services, app code, and deployment scripts.
- `ros2/packages/`: ROS 2 nodes/packages.
- `ros2/workspaces/`: Colcon workspaces and overlays.
- `ros2/configs/`: ROS 2 YAML and parameter configurations.
- `ros2/launch/`: ROS 2 launch files.
- `ros2/scripts/`: ROS 2 helper scripts.
- `docs/`: High-level architecture notes.
